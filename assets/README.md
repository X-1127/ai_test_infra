# Assets Directory

This directory contains static assets for the LLM Mock Server project.

## Icon Files

- `icon.ico` - Application icon for Windows executable

## Adding Icons

To add a custom icon:

1. Create or convert your icon to `.ico` format
2. Name it `icon.ico`
3. Place it in this directory
4. Rebuild the application using `build.bat`

## Icon Specifications

- Format: `.ico`
- Recommended sizes: 16x16, 32x32, 48x48, 64x64, 128x128, 256x256
- Color depth: 32-bit (RGBA)

## Tools for Creating Icons

- [GIMP](https://www.gimp.org/) - Free image editor
- [IcoFX](https://icofx.ro/) - Dedicated icon editor
- [Online converters](https://convertico.com/) - Web-based conversion tools
